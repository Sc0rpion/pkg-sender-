# PS5 PKG Sender — Пакет Synology DSM (.spk)

Готовый пакет для установки сервера **PS5 PKG Sender** на сетевые накопители **Synology NAS** под управлением **DSM 7.x** и **DSM 6.x**.

---

## 📦 Что включено в пакет
- **Служба сервера (`server/`)**: многопоточный Python HTTP/REST сервер для стриминга PKG и управления установкой.
- **Мастер установки Synology (Wizard)**: при ручной установке через Центр пакетов DSM предлагает указать путь к папке с играми (например, `/volume1/downloads` или `/volume1/PS_Games`) и порт (по умолчанию `9898`).
- **Служба автозапуска и управления (`start-stop-status`)**: корректный запуск, остановка и перезапуск через интерфейс DSM.
- **Интеграция в главное меню DSM (`ui/`)**: иконка приложения в интерфейсе DSM с автоматическим открытием веб-интерфейса в браузере.
- **Автоматическое сохранение БД и конфигурации**: при обновлении пакета (`preupgrade` / `postupgrade`) база данных и настройки пользователя сохраняются.
- **Права и безопасность DSM 7 (`conf/privilege`)**: настроены профили безопасности для беспрепятственного чтения сетевых папок.
- **Правила брандмауэра (`conf/resource`)**: регистрация портов 9898 (TCP) и 12802 (UDP).

---

## 🚀 Сборка пакета (.spk)

Для сборки готового `.spk` файла запустите скрипт:
```bash
./synology/build_spk.sh
```

Готовый файл пакета появится в корне проекта:
```text
pkg-sender.spk
```

---

## 📥 Установка на Synology NAS

1. Откройте веб-интерфейс **DSM** в браузере.
2. Перейдите в **Центр пакетов** (Package Center).
3. Убедитесь, что на NAS установлен пакет **Python 3** (доступен в официальном Центре пакетов).
4. Нажмите кнопку **Ручная установка** (Manual Install) в правом верхнем углу.
5. Выберите файл `pkg-sender.spk` и нажмите **Далее**.
6. В мастере установки введите:
   - Путь к вашей папке с `.pkg` файлами (например, `/volume1/downloads`).
   - Порт веб-интерфейса (по умолчанию `9898`).
7. Подтвердите установку.

После завершения установки в меню DSM появится иконка **PS5 PKG Sender**, а сервер запустится в фоновом режиме.
Веб-интерфейс будет доступен по адресу: `http://<IP_ВАШЕГО_NAS>:9898/`.

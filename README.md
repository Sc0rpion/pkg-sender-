# PS5 PKG Sender & Synology NAS SPK (Payload & Server)

Комплексное решение для высокоскоростной удаленной установки PKG-пакетов на PlayStation 5 (и PlayStation 4) напрямую с сетевого хранилища Synology NAS или ПК.

Система состоит из двух взаимодействующих компонентов:
1. **`server/` (Synology NAS / Linux / PC Backend)** — оптимизированный сервер на Python с автоматическим отслеживанием файлов (Watchdog), парсером заголовков PKG (`\x7FCNT` / `\x7FFIH`), извлечением обложек (`icon0.png`), базой SQLite, HTTP Range сервером (порт 9898), UDP-анонсером консолей и адаптивным мультиязычным веб-интерфейсом. Также доступен в виде готового **SPK-пакета для Synology DSM 7+**.
2. **`payload/` (PKGri)** — автономный фоновый C-демон для PS5 (FreeBSD / Prospero), принимающий команды установки, управляющий процессом через Sony `AppInstUtil`, опрашивающий свободное место и встроенный накопитель, а также предоставляющий встроенный Web GUI прямо на консоли.

---

## 🚀 Основные возможности

- **Готовый пакет Synology DSM 7 (`pkg-sender.spk`)**: установка в один клик через «Центр пакетов», автозапуск службы (`sc-pkg-sender`), автонастройка портов и прав доступа к общим папкам.
- **Интеллектуальная группировка и сортировка каталога**:
  - Игры и патчи автоматически объединяются по Title ID (например, `PPSA29180`).
  - Базовая игра (`Game`), патчи (`Patch`) и дополнения (`DLC`) выстраиваются в строгой последовательности как на сервере, так и в интерфейсе консоли.
- **Аудит прав доступа в Web GUI**:
  - Если в Synology DSM у сервисного аккаунта пакета нет прав на чтение выбранной папки, в веб-интерфейсе отображается предупреждение с подсказкой по выдаче разрешений.
- **Поддержка многопоточной докачки и HTTP Range (206 Partial Content)**: максимальная скорость передачи пакетов по локальной сети (до 1 Гбит/с и 2.5 Гбит/с).
- **Автоматическое обнаружение (UDP Discovery)**: сервер и консоль мгновенно находят друг друга по сети без необходимости ручного ввода IP.

## 📁 Структура проекта

```text
├── pkg-sender.spk          # Готовый пакет для установки в Synology DSM 7+
├── server/                 # Серверная часть (NAS / PC) на Python
│   ├── main.py             # Точка входа сервера и корректная остановка (Graceful Shutdown)
│   ├── server.py           # HTTP сервер (порт 9898, Range 206, REST API)
│   ├── scanner.py          # Мониторинг папки с играми (Watchdog + аудит прав доступа)
│   ├── parser.py           # Парсер метаданных PKG (SFO, param.json, извлечение icon0)
│   ├── db.py               # SQLite база каталога с группировкой по Title ID
│   ├── feedback.py         # Веб-интерфейс сервера (Web GUI) с уведомлением о правах доступа
│   ├── config.py / .json   # Конфигурация папки сканирования и порта
│   ├── logger.py           # Логирование событий (app.log)
│   └── locales.json        # Локализация Web GUI (RU, EN, FR, DE, ES, JA)
├── synology/               # Исходные файлы для сборки Synology DSM пакета (SPK)
│   ├── INFO                # Метаданные пакета DSM (версия 1.2.0-0001)
│   ├── build_spk.sh        # Скрипт сборки pkg-sender.spk
│   ├── conf/               # Конфигурация прав (privilege) и ресурсов
│   └── scripts/            # Скрипты жизненного цикла (start-stop-status, postinst)
└── payload/                # Клиентский демон для PS5 (C / Prospero)
    ├── main.c              # Исходный код демона (Prospero / POSIX, HTTP/UDP, Standby)
    ├── webui.c             # Встроенный Web GUI консоли (порт 12800)
    ├── installer.c         # Взаимодействие с системным AppInstUtil
    ├── Makefile            # Сборочные правила для PS5 ELF
    ├── build.sh            # Скрипт сборки
    ├── pkg-receiver.elf    # Скомпилированный бинарный файл для отправки на PS5
    └── README.md           # Документация пейлоада
```

## 📦 Установка на Synology NAS (DSM 7+)

1. Скачайте файл **`pkg-sender.spk`**.
2. В веб-интерфейсе Synology DSM откройте **Центр пакетов (Package Center)**.
3. Нажмите **Ручная установка (Manual Install)** и выберите `pkg-sender.spk`.
4. В мастере установки укажите путь к папке с PKG-файлами (например, `/volume1/downloads`) и порт (по умолчанию `9898`).
5. **Предоставление прав на общую папку**:
   - Откройте **Панель управления (Control Panel)** -> **Общая папка (Shared Folder)**.
   - Выберите вашу папку с играми -> **Редактировать (Edit)** -> вкладка **Разрешения (Permissions)**.
   - В выпадающем списке выберите **Пользователь системного приложения (System internal user)**.
   - Для пользователя **`pkg-sender`** установите галочку **Чтение/Запись (Read/Write)** или **Чтение**.
   - Нажмите **Сохранить**.
6. Откройте веб-интерфейс сервера: `http://<IP_NAS>:9898`.

## 🎮 Запуск на PlayStation 5

1. Загрузите **`payload/pkg-receiver.elf`** на PS5 любым удобным способом (через Netcat на порт 9020/9021 или загрузчик полезной нагрузки).
2. После запуска на экране появится уведомление:
   ```text
   PKGri: listening on 12800
   IP: <IP_PS5>
   ```
3. Сервер на Synology NAS автоматически определит консоль через UDP-маяк. Вы также можете открыть веб-интерфейс консоли по адресу `http://<IP_PS5>:12800`.

## 🌐 Сетевые порты

| Порт / Протокол | Назначение |
|-----------------|------------|
| **9898 TCP** | HTTP-сервер Synology NAS / PC: раздача файлов, каталог `/catalog`, Web GUI |
| **12800 TCP** | HTTP REST API & Web GUI на консоли PS5 (управление очередью, запуск установки) |
| **12801 UDP** | Discovery Beacon (рассылка маяков консоли для автообнаружения) |
| **12802 UDP** | PC Announce (широковещательные анонсы сервера в локальной сети) |

## 🛠️ Сборка из исходников

### Сборка Synology SPK пакета:
```bash
bash synology/build_spk.sh
```
Готовый пакет будет помещен в корень проекта: `pkg-sender.spk`.

### Запуск сервера на ПК / Linux без Synology:
```bash
python3 server/main.py
```

### Сборка ELF-пейлоада для PS5:
Требуется [ps5-payload-dev/sdk](https://github.com/ps5-payload-dev/sdk):
```bash
cd payload
make
```
